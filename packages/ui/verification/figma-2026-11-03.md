# Figma comparison — waves 1–6, 2026-11-03

The visual-coverage row of the [0.3.0 hand-off](0.3.0.md), first part: the 33
core components of waves 1–6 other than Input Text, by owner decision. Wave 7
and Input Text were compared with Figma in their own reviews of 2026-10-24 to
2026-10-26, and the DOM changes since (#89, #90) were pixel-compared unchanged.

## Method

Reference data comes from the Stylos Figma file (`WUc07ZBtjRvypXtsOlbVut`)
through the Figma MCP, read-only: each component set's metadata — every variant
by name with its width and height — and a screenshot of the set, collected into
`build/figma-compare/`. The comparison page served by `npm run ui:verify:browser`
at `/figma.html` renders every Figma variant through the package with the
arguments its name maps to (`size=medium, state=disabled` → `size`, `state`),
in a cell as wide as the Figma variant, beside the Figma screenshot, and
compares the rendered size with Figma's within 1 px — Figma reports whole
pixels. Overlays open one at a time through their example's trigger. Headless
Chrome 156 ran the page for all 33 at 1280-wide, light theme; sizes do not
depend on the theme.

Not compared by size: Figma's `hover` and `active` states, which are native
pointer states with no argument; Toggle's `mixed`, which is not in the web API;
Loader's animation frames; Select's `is filled` and `active / focus`; Icon,
whose node is a single symbol, not a set. They are in the page for the eye.

## Results

1,408 Figma variants. Every size matches within 1 px — heights everywhere,
widths wherever the example's content and container match Figma's:

- **Exact in every variant:** Badge, Button (Base), Button Icon (Base), Button
  Inner, Checkbox Input and Label, Radio Input and Label, Toggle Input and
  Label, Tag (Fill), Link, Loader, Indicator Status and Special, Label, Table
  Cell Heading and Text, Table Row Head, Modal.
- **Heights exact, widths from the example:** Dropdown Item Default, Parent,
  Checkbox and Toggle (the example list is 210 px wide, Figma's 220), Select
  (example field 320 px), Table Row Body (example table 520 px), Drawer (full
  window height by design, Figma frame 500), Tooltip's text type (shorter
  example text). Checkbox, Radio and Toggle Text match at one line; the
  example's longer text wraps at the larger sizes.

**One finding — Dropdown panel padding.** Item heights and the 4 px gaps match.
Figma's list has 4 px above the first item at every size but 4 / 8 / 12 / 16 /
20 px below the last, from extra small to extra large; the code has 4 px on
both ends. A six-item hug panel is 174 / 214 / 254 / 294 / 334 px in Figma and
174 / 210 / 246 / 282 / 318 px in code (medium: `4857:4332`, slot 252 high,
last item ending at 240). **Owner decision, 2026-11-03: Figma is right**, superseding the 2026-10-24
amendment in the Dropdown contract that kept 4 px on all four sides. The code now has the growing
end padding; re-measured, six-item hug panels are 174 / 214 / 254 / 294 / 334 px
and fixed panels 186 / 229 / 272 / 315 / 358 px, equal to Figma at every size —
the fixed heights, which the old padding also missed, confirm the reading.

Button, Button Icon and Tag were compared with their Base and Fill sets; the
Outline, Ghost and Outline Tag sets were not part of this run.

## For the owner's eye

`/figma.html` shows each set's Figma screenshot beside every variant rendered by
code, in either theme, with the size table and the explanation of each known
measurement difference. Colour, typography and detail are judged there; Figma
references are light-theme screenshots only.
