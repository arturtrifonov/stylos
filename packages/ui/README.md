# `@stylos/ui`

The Svelte 5 component package, built to [SPEC 0009](../../docs/specs/0009-stylos-ui-package.md) against the contracts in [`docs/components/registry/`](../../docs/components/registry/). The stack and the layering are [ADR 0002](../../docs/decisions/0002-frontend-stack.md); the version is the system's, in lockstep ([`ARCHITECTURE.md`](../../ARCHITECTURE.md) §9).

## The layers, top is thinnest

1. **`dist/tokens.css`** — the custom properties, generated by `npm run tokens:css` ([SPEC 0007](../../docs/specs/0007-tokens-to-css.md)). Nothing below restates a value.
2. **Per-component CSS** (`src/components/<name>/<name>.css`) — selectors keyed on data attributes carrying the contract's values. Every value is a `var(--stylos-…)`; a hex or a raw `px` outside `tokens.css` fails Stylelint (`npm run lint:css` at the root).
3. **Behaviour** (`src/behaviors/`, when a component needs one) — framework-free, operating on elements.
4. **`.svelte` wrapper** — takes the contract's props, writes the data attributes the CSS reads. The only Svelte-specific file; layers 1–3 survive a framework change.

## Generated, never hand-written

- `src/components/<name>/props.ts` — from the entry's `api` by `tools/build-ui-types.mjs`, so props ↔ `api` is checked by the compiler.
- `dist/` — `tokens.css` + `tokens.json` (`tokens:css`) and `package/` (`svelte-package`).

`npm run ui:generate` at the root rebuilds all of it; `npm run ui:build` builds the package (generation runs as its `prebuild`).

## Adding a component

Per [SPEC 0009](../../docs/specs/0009-stylos-ui-package.md) §5, contract first: the entry's `api` is corrected to describe the web component in the same session the `.svelte` is written. Then a directory under `src/components/` named by the entry's slug, the authored CSS and wrapper, an export in `src/index.ts` — and the generators produce the props type and the workshop story.
