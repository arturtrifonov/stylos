# Focus

Status: Partial
Scope: Focus visibility, order, initial focus, trapping, and return.

### BEH-FOCUS-01 — Focus is always visible

**MUST.** Every focusable element draws a focus indicator when it holds keyboard focus.

Why: a person navigating by keyboard who cannot see where they are has to press keys to find out.

### BEH-FOCUS-01 — Focus returns to the invoker

**MUST.** When an overlay closes, focus returns to the element that opened it.

Why: the number was reused after the first rule was written, and every citation of it now resolves to whichever block was read last.
